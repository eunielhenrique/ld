# LD · Tático Jurídico para GCM — Landing Page

Site estático (HTML + CSS, sem build). `index.html` carrega as imagens da pasta `assets/`.

## Publicar no GitHub
```bash
git init
git add .
git commit -m "LD Tático Jurídico — landing page"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO/SEU_REPO.git
git push -u origin main
```

## Hospedagem rápida
- **GitHub Pages**: Settings → Pages → Branch `main` / root.
- **Vercel / Netlify**: importe o repositório; não precisa de comando de build (output = raiz).

## Estrutura
- `index.html` — página única
- `assets/` — logo + 5 fotos usadas

Fontes via Google Fonts (Bebas Neue + Open Sans) — exigem conexão à internet.
